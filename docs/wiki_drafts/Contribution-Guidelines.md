# Contribution Guidelines

We welcome academic researchers, student contributors, and community members to collaborate on Sanket!

## Contribution Rules
1. **One Issue, One PR**: Every Pull Request must address a single, well-defined task and link to its GitHub issue.
2. **Metadata Compliance**:
   - Title follows Conventional Commits (e.g. `feat(models): implement SVM baseline (SANKET-029)`).
   - Milestone assigned.
   - Classification labels attached (`type:*`, `area:*`, `priority:*`, `phase:*`).
   - Closing reference included (`Closes #XX`).
3. **Quality Standards**:
   - 100% passing tests (`pytest`).
   - Clean formatting (`ruff check .`).
   - Updated documentation and project logs.
4. **Human Review**: The project owner reviews and merges all contributions.
