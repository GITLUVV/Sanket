## How to Propose an ADR
1. Copy `docs/decisions/ADR_TEMPLATE.md` to a new file `ADR-XXXX-<short-title>.md`.
2. Fill out all sections: Decision, Context, Options Considered, Chosen Approach, Reasons, and Consequences.
3. Submit via a Pull Request associated with the relevant SANKET issue.
4. Mark status as `Proposed` until approved by the project owner.
